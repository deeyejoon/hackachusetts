# Project Structure

Three slices in one repo. See `docs/INTEGRATION.md` for how they connect.

```
/
├── Package.swift            PulseCore Swift Package manifest
├── Sources/
│   ├── PulseCore/           the engine (macOS + iOS buildable, headless-testable)
│   │   ├── Models/          HRSample, ContentEvent, SpikeEvent
│   │   ├── Sources/         HeartRateSource protocol, MockHeartRateSource
│   │   └── Engine/          BaselineTracker, CorrelationEngine, WeeklyReport
│   ├── PulseKit/            iOS-only: WhoopBLESource, LiveAlertService, ScreenKeywordCapture
│   └── PulseDemo/           runnable CLI simulation of the whole pipeline
├── Tests/PulseCoreTests/    engine unit tests
├── ios/                     SwiftUI app sources (branded "Sage")
│   ├── SageApp.swift        @main; creates + injects SignalStore
│   ├── Models/              ChatMessage, PhysioSignal (mirror of SpikeEvent)
│   ├── ViewModels/          ChatViewModel, SignalStore (single source of truth)
│   ├── Networking/          ChatAPIClient, PulseCoreBridge (SpikeEvent -> PhysioSignal)
│   ├── Views/               4 screens + bubble/typing components
│   └── Theme/               SageColors, SageFonts
├── backend/                 Flask + Hugging Face chatbot (app.py, chat_service.py, safety.py, config.py)
├── docs/                    INTEGRATION.md, DEVICE_INSTALL.md
├── project.yml              XcodeGen spec — source of truth for the Xcode project
└── .kiro/steering/          these rules
```

## Generated artifacts (do NOT hand-edit, do NOT commit)

- `Sage.xcodeproj/` — generated by XcodeGen from `project.yml`. Gitignored.
- `ios/Info.plist` — generated from `project.yml`'s `info.properties`. Gitignored.

To change the Xcode project (bundle id, signing, backend URL, added files), edit
`project.yml` and run `xcodegen generate`. Never edit the `.pbxproj` by hand.

## Key seams

- **`HeartRateSource`** protocol — swap mock vs. real WHOOP without touching the engine.
- **`SignalStore`** (iOS) — the one place signals live; Insights + Chat observe it.
- **`PulseCoreBridge`** — converts engine `SpikeEvent`s to app `PhysioSignal`s. Active
  because the app links PulseCore; it's guarded by `#if canImport(PulseCore)`.
- **`signal_context`** on `POST /chat` — optional, backward-compatible physiological
  context the app sends the backend.

## Conventions

- iOS: one type per file, grouped by role (Models/ViewModels/Views/Networking/Theme).
  Reference colors via `Color.sageMoss` etc., never raw hex in views.
- Swift package: public API is documented; keep iOS-only frameworks in PulseKit.
- Backend: env-driven config, no hardcoded secrets, snake_case JSON.
