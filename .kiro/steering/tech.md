# Tech Stack & Commands

## Stacks

- **PulseCore / PulseKit / PulseDemo** — Swift 5.9 Swift Package. PulseCore + tests +
  PulseDemo build and run on macOS from the command line. PulseKit is iOS-only.
- **iOS app (Sage)** — SwiftUI, iOS 16+. Project generated by XcodeGen from `project.yml`.
- **Backend** — Python 3 + Flask, calls the Hugging Face Inference API
  (`mistralai/Mistral-7B-Instruct-v0.2`). Config via `.env` (python-dotenv).

## Common commands

Swift engine (no Xcode, no hardware):
```bash
swift build
swift test            # 13 unit tests
swift run PulseDemo   # end-to-end spike-detection + weekly-report simulation
```

iOS app:
```bash
brew install xcodegen      # one-time
xcodegen generate          # regenerate Sage.xcodeproj after cloning or editing project.yml
open Sage.xcodeproj        # pick a simulator, ⌘R
```

Backend:
```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # set HF_API_TOKEN
PORT=5001 python app.py     # see port note below
```

Physical-device install: see `docs/DEVICE_INSTALL.md`.

## Guardrails (don't break these)

1. **PulseCore must keep building and testing on macOS from the CLI.** Keep anything
   needing CoreBluetooth / ReplayKit / Vision / UserNotifications in **PulseKit**,
   behind `#if canImport(...)`. Never import those from PulseCore.
2. **The crisis check in `backend/safety.py` runs BEFORE any model call or signal
   use.** Don't move or weaken it.
3. **`signal_context` on `/chat` stays optional and backward-compatible.** Omitting it
   must produce the same request/response as before.
4. **Don't hand-edit `Sage.xcodeproj` or `ios/Info.plist`** — they're generated. Edit
   `project.yml` and regenerate. Both are gitignored.
5. Cross-slice shape changes get reflected in `docs/INTEGRATION.md` and the iOS
   `PhysioSignal` together.
6. Prefer extending over replacing existing code. The mocked Connect/Community screens
   are acceptable placeholders.

## Gotchas

- **Port 5000 is taken on macOS by AirPlay Receiver** (`ControlCenter`). Run the
  backend on **5001**, or disable AirPlay Receiver in System Settings.
- A **physical phone can't reach `127.0.0.1`** — point `SAGE_BASE_URL` in `project.yml`
  at the Mac's LAN IP (`ipconfig getifaddr en0`), then regenerate. The Simulator uses
  the `127.0.0.1` fallback automatically.
- Free (no paid account) device installs **expire after 7 days**; re-run from Xcode.
- Campus/public Wi-Fi may block phone↔laptop traffic; a phone hotspot is the fallback.

## Verification expectations

- After engine changes: `swift build` + `swift test` green.
- After iOS/project changes: `xcodegen generate` then a Simulator build succeeds.
- After backend changes: `/health` responds and the crisis short-circuit still fires
  with no model call.
